# Fictieve HEIC-testfoto's

Vier met SPECIMEN / FICTIF gemarkeerde kaarten van dezelfde verzonnen persoon.
Gegenereerd met `../prepare-live-fixtures.mjs`, daarna met macOS `sips -s format heic`
naar echte HEVC/HEIF-bestanden omgezet. Geen foto's van echte identiteitsbewijzen.
De vaste waarden staan bij `cin1` en `lic1` in `../waarheid.json`.

Dit test echte HEIC-decodering en de uploadroute. Het is geen bewijs dat de
fysieke iPhone-camera, iCloud-bestandskiezer of alle iOS-versies zijn getest.
